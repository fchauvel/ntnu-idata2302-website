============
Code Samples
============

The code examples that accompany the lecture notes live in their own
repository, `aldast-examples <https://github.com/fchauvel/aldast-examples>`_.
They are organised by module, then by topic, and finally by programming
language. Each example has a short README, and most come with tests.

To get all of them:

.. code-block:: shell

   $ git clone https://github.com/fchauvel/aldast-examples.git
