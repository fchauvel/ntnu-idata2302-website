============
Optimization
============

Now we have studied the common algorithms and data-structures, we move
on to "optimization problems". For example, finding the shortest
paths, or the minimum spanning tree (as we have seen with graphs),
finding the cheapest set of items, etc. We start with *combinatorial
search*, which finds the best solution among a finite set by trying
possibilities, cleverly, until the *branch-and-bound* algorithm. We then
look at *dynamic programming*, a method to speed up some recursive
optimization algorithms. Finally, we give pointers to *heuristic search*,
for the problems that are too large, or infinite.
